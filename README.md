# Nordic Living – Starter

React + Vite + Tailwind starter inspired by the Nordic Living furniture design.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Structure
- `src/data/content.js` – all text, products, categories and images (edit here)
- `src/components/` – Header, Footer, ProductCard, etc.
- `src/pages/` – Home, Shop, Cart, NotFound
- `src/context/CartContext.jsx` – cart and wishlist state (localStorage)

Images are placeholders from picsum.photos. Replace them with your own product photos.
